indicators.age_group_trends(
    rows
    characteristic
    age_groups
    sex
    n_permutations=breaks.N_PERMUTATIONS
)

Trajectory summary per age group for one series and sex.

Args: rows: Tidy rows as produced by :func:tidy. characteristic: The characteristic to summarise. age_groups: Age-group labels to report, in display order. sex: The sex category to hold fixed. n_permutations: Permutation count for the break test; the age-specific mode lowers this for speed across many groups.

Returns: dict: Age-group label to :func:trajectory result, in the order requested; groups absent from the data are omitted.

build_age_specific

indicators.build_age_specific(spec)

Build age-specific trajectories for a time-series indicator.

The source already carries every age group; this mode tidies them all and summarises each age group by sex, so the report can show whether the same regime appears at every age or only at some. No separate tidy CSV is published, because the all-ages indicator already publishes the same table; this mode adds only the per-age trend summary.

build_cross_section

indicators.build_cross_section(spec)

Build a sub-provincial cross-sectional indicator.

Unlike the time-series indicators this does not run regime tests: the source is published as overlapping three-year averages, so the value it adds is the spread across regions in a single period, not a trajectory.

build_economic_accounts

indicators.build_economic_accounts(spec)

Build a determinant series from the BC Economic Accounts workbook.

These are economic series, not health outcomes: they exist so that milestone M4 can ask whether health outcomes move with economic conditions. The build extracts one worksheet, one geography (British Columbia by default), and writes a tidy series with a stated unit.

Args: spec: The indicator specification.

Returns: dict: The build summary, including the written paths.

build_regional_timeseries

indicators.build_regional_timeseries(spec)

Build a sub-provincial multi-period regional indicator.

Unlike the cross-section mode, each region contributes a row per reference period and gets a trajectory summary; unlike the provincial time-series modes, the periods are pooled averages (two- or three-year), so regime dating is left to the stationarity machinery, which reports undetermined when the series is too short.

The summary JSON holds, for every series slice (each indicator and age group at the headline sex), the across-region spread per period and the per-region trajectories, at every region level present plus the province.

dispersion

indicators.dispersion(
    rows
    cause
    characteristic
    sex
    indicator='Mortality'
    level='health_service_delivery_area'
)

Summarise the spread of one cross-sectional indicator across regions.

Returns the sorted regional values for the most recent reference period, with the highest and lowest regions, their ratio, and the range. Only regions at level are compared, so authorities are not double-counted alongside the service delivery areas they contain.

regional_spread

indicators.regional_spread(rows, level, sex, indicator=None, age_group=None)

Spread of one series slice across regions, per reference period.

Like :func:dispersion but for multi-period regional series: returns a dict keyed by reference period, each entry holding the sorted regional values, the extremes, the ratio, the range, and the mean at the given region level. Province rows are never counted.

regional_trajectories

indicators.regional_trajectories(
    rows
    level
    sex
    indicator=None
    age_group=None
)

Trajectory summary per region for one slice of a regional series.

Args: rows: Tidy rows as produced by :func:tidy_regional_timeseries. level: Region level whose regions to summarise. sex: The sex category to hold fixed. indicator: Indicator name to hold fixed; None keeps rows with no indicator dimension. age_group: Age group to hold fixed; None keeps all.

Returns: dict: Region name to :func:trajectory result, in sorted order; regions absent from the data are omitted. Pooled multi-year periods usually give five points, so the trajectory carries the overall slope and the stationarity verdict (normally undetermined), not dated regimes.

tidy_regional_timeseries

indicators.tidy_regional_timeseries(
    rows
    province
    sexes
    indicators=None
    age_groups=None
    characteristics=None
)

Tidy sub-provincial multi-period rows, keeping the province row.

Unlike :func:tidy_regions, the province’s own row is kept (labelled at province level) so regional trajectories can be compared against the provincial series, and each region contributes one row per reference period.

Args: rows: Raw rows as read from a WDS table CSV. province: Province name; rows whose geography is the province or ends with ", <province>" are kept. sexes: Sex categories to keep, in display order. indicators: Indicator names to keep (from the table’s Indicators dimension); None keeps all. age_groups: Age-group labels to keep; None keeps all. characteristics: Characteristic labels to keep; None keeps all.
