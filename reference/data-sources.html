Data sources

Status: v0.1 (provisional, milestone M2 in progress). This catalogue is maintained alongside the machine-readable source list at data/catalogue/sources.yml, which the acquisition pipeline reads. Every URL below was verified reachable at the time of writing (see the data quality report).

This is the project’s inventory of the data that describe the state of health in BC. Data is construed broadly: microdata, indicator tables, dashboards, report figures, and catalogue/API discovery layers all qualify, provided licence and governance checks pass. The aim is the best use of all publicly available information that can be appropriately used — not “microdata or nothing” (roadmap, milestone M2).

How to read an entry

Each source is catalogued with the following fields (see data/catalogue/sources.yml):

Field Meaning
key stable identifier used by the pipeline
form microdata, indicator_table, dashboard, report_figure, api, or catalogue (a discovery layer)
domains which measurement-framework domains it can serve
resolution individual, neighbourhood, HSDA, LHA, health authority, provincial, international
coverage the published time span of the series
frequency / refresh how often observations are dated and how often the source is updated
licence / access reuse terms and how you obtain it
origin bc, canada, or international
temporal behaviour expected behaviour: trending, seasonal, shock_prone, or stable
quality notes suppressions, revisions, definitional breaks

International and external-driver sources

Source Publisher Form Role Resolution Frequency
WHO data WHO indicator tables global reference, pandemic context international annual

External drivers are catalogued with their origin and the mechanism by which they reach BC in data/catalogue/sources.yml (reaches_bc_via): for example, migration flows (statcan_demography), cross-border fire and smoke (cwfis), and global pandemic conditions (who_data).

Microdata access routes

Individual-level sources are catalogued as access routes — the approval process, not the data:

Source Provider Scope Access
Population Data BC Population Data BC BC administrative health records application, ethics review, secure environment
Microdata access Statistics Canada national survey microdata Research Data Centres / remote access / custom tabulations

These are catalogued even though the data cannot be committed: they set the ceiling on what resolution is attainable and are the route to individual-level indicators. No individual-level data enters the repository.

Governance and licences

  • Licences vary by source and are recorded per entry. Check the record before redistributing anything.
  • No individual-level data is stored in the repository. Only aggregate/public sources are fetched, and fetched data are reproducible artefacts (data/raw/) that are never committed.
  • First Nations data are governed by First Nations principles and specific agreements; reuse must respect (First Nations Information Governance Centre, n.d.).

Reproducing the catalogue

uv run sohbc validate   # schema check
uv run sohbc list       # list sources
uv run sohbc check --all --include-download   # re-verify URLs
uv run sohbc fetch --all

See How to ingest a data source.
